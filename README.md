# WeatherCast – Weather Forecasting System  
**DSA Course Project**

WeatherCast is a simple yet efficient Weather Forecasting System built as part of our **Data Structures and Algorithms (DSA) project**.  
The main objective of this system is to demonstrate the practical application of core DSA concepts in processing, organizing, and predicting weather information.

---

## 🚀 Features

- 🌤 **Real-Time Weather Input**  
  Accepts or loads temperature, humidity, wind speed, and other parameters.

- 📊 **DSA-Based Data Handling**  
  Utilizes arrays, linked lists, trees, or hash structures (depending on implementation).

- 🔍 **Efficient Searching & Sorting**  
  Helps analyze and retrieve weather data quickly.

- 📅 **Forecast Generation**  
  Produces basic short-term weather predictions based on stored data patterns.

- 📁 **File Handling Support**  
  Saves and loads weather information for persistent storage.
